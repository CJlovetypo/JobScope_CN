# 求职入口合并与替代验证报告

日期：2026-09-22。依据：用户明确要求删除 campus-job-fit、internship-job-fit、social-job-fit，删除前确认 job-search 可以完整替代。此轮只合并入口与迁移依赖，不新增业务判断规则。

## 设计与能力核对

求职只加载 `job-search/SKILL.md`。入口读取共享决策规则，再按已明确方向加载差异规则；统一 CLI 直接进入共享核心，不再调用三个旧目录。`job-radar`、`recruitment-link-repair` 保持独立职责。

`job-search/runtime/campus|internship|social` 保存内部方向规则、数据、脚本和历史产物，不包含 SKILL.md 或 agents 元数据，不是三个改名后的 Skill。内部脚本保留维护与测试用途，新任务统一绑定 task，由 job-search 执行。

| 原有能力 | 当前承接位置 | 验证 |
| --- | --- | --- |
| 意图、必要澄清、沿用已知条件、任务修订 | job-search + decision-policy/task-contract | 已知方向不重问、发现不索要简历、范围修订及冲突校验 |
| 校招届别、学历、专业与经历判断 | modes/campus + runtime/campus/references | 校招类型、资格及模式隔离回归 |
| 实习身份与到岗安排 | modes/internship + runtime/internship/references | 实习方向、时间安排及模式隔离回归 |

| 招聘来源、全量/定向采集与来源修复 | shared/job-search-core + 独立链接修复 Skill | 采集器、缓存指纹、方向证明、部分覆盖、修复与历史检索回归 |
| 城市、公司标签与简介 | 共享标签 + 按方向隔离的城市索引 | 日常使用只读，主动维护独立；三份城市索引迁移前后哈希一致 |
| 简历文本提取 | runtime/<方向>/scripts/extract_resume.py → 共享提取器 | 三方向真实调用、原文件不变、跨方向写入拒绝 |
| 固定批次全文评估、并行台账和续跑 | 共享 batches/evaluation-scope | 三方向统一 CLI 提交、合并、关闭及完成后不重复领取 |
| 候选清单、四页签 Excel | 共享 discovery/reports | 三方向候选发现及 v5 Excel 实际生成；既有工作簿读回测试 |
| 公司资料、来源、城市主动维护 | 共享维护器与内部运行工具 | 隔离测试仓库不含旧目录，显式维护仍可执行 |

另外修复了公司简介 `status` 误走严格合并的问题：已有 partial 或异常历史线索应显示为资料问题，不能使只读查询失败，也不能被统计为核实事实。写入维护继续使用原校验，不改变资料认定标准。
