# 匹配判断模型 v5 迭代 PRD

日期：2026-09-22。业务范围：用户已确认审核稿 R1–R7，并单独确认工作年限弹性规则。实施与验收记录见[测试报告](匹配判断模型v5测试报告.md)。原审核发现留在[审核稿](匹配判断模型迭代审核稿.md)。

## 问题与目标

旧报告中，58个岗位全部显示能力低、暂不建议投递，其中大量依据实际是“未提供对应任务证据”。程序还拒绝把能力unknown作为已完成结果，导致Agent可能为完成批次而错误下结论。部分资格判断混合学历/专业、总年限/相关实践；城市与薪资的能力边界和评估位置也不清楚。

本次要使缺证、已证实不符和有条件支持可区分，使总体结论、投递动作和说明一致。已完整审阅但关键资料缺失的岗位可以交付；同时明确审阅完成不等于已确定适合。

## 已批准的业务规则

| 维度 | 判断与行为 |
| --- | --- |
| 证据状态 | 每个核心要求记录符合、部分符合、不符、不确定；缺证不等于不会。能力低需要已证实核心冲突，不能用简历缺写作为负面证据。 |
| 资格 | 学历、专业及方向真实门槛分别核对；未要求与本人资料未给分开。确定冲突与未知并存时保留两者。 |
| 工作年限 | 总年限、相关经验分别保留JD要求、已知事实和差距。默认作为经验参考，结合职责、责任深度和成果判断放宽依据；缺证为不确定，不设统一“可少几年”，不保证雇主接受。 |
| 工作意愿 | 只来自用户明确偏好；软偏好不能变成否决。城市和薪资不重复进入此维度。 |
| 城市 | 仅匹配城市意愿。未指定、不限、部分符合、明确不符及城市未知分别记录。城市未知不阻止完整JD其他维度审阅。同城距离、离家远近和通勤时长不支持，明确告知并忽略，不产生后续地址/交通核验目标。 |
| 薪资 | 明确告知JD薪资可能不准，仅作参考，不代表实际录用待遇。不能按区间硬筛或保证达到期望。可比时参考，不可比/未披露为未知；未给偏好不主动设目标。仅在主要判断相当时辅助排序，不改变主要档位或行动。 |
| 证据充分性 | 单列依据、缺项与充分程度，不把它当能力分；不确定必须说明缺什么。 |
| 补问 | 跨岗位聚合共用且能改变结论的事实，每轮最多3组；不用逐岗重复问，不强制上传简历文件。 |

行为和结构权威定义：[assessment-v5.md](../shared/job-search-core/references/assessment-v5.md)。审核后发现新的业务取舍仍须先review；按已批准规则修复实现和测试不重复请求确认。

## 架构与执行

保留统一入口job-search、shared共用判断、三个招聘方向薄适配的架构。本次是共用判断元能力升级，不另建互相冲突的多套Skill。

新prepare固定assessment_model_version=5，允许合法空evidence和未知个人字段。完整判断与有限判断在task-check分别呈现。方向、来源范围、JD全文、用户明确的评估范围及来源证据要求继续生效。

固定批次携带v5规则入口；Agent真正阅读全文并写出事实对照，程序校验ID、指纹、版本、状态及行动一致性。未知结果可以submit→merge→done→render，不因缺证重复分派。新的个人事实/JD出现后按既有指纹规则新建运行重评。

旧v4运行保留读取和续跑兼容，旧报告不覆盖。新运行拒绝直接采用v4判断，不能只换版本、指纹或把low批量替成unknown。历史快照回放单独标注资料日期，不等于来源刷新。

## 最终交付

四页签保持：岗位匹配、待核实与未评估、公司简介、覆盖说明。岗位页从12列扩为15列，原A–L位置不变，新增城市意愿匹配、薪资参考、证据充分性。官方JD链接仍在L列。

| 情形 | 总体表达 | 行动 |
| --- | --- | --- |
| 已证实关键冲突 | 明确不符（资格冲突单独说明） | 暂不建议投递 |
| 无明确冲突，但关键事实未知 | 信息待确认 | 补资料后判断 |
| 核心有真实支持，存在迁移或准备事项 | 有条件匹配 | 投递前准备 |
| 主要要求充分支持 | 匹配依据较充分 | 可以考虑投递 |
| 仅薪资差距/未知 | 主要结论保持 | 附参考说明 |

交付披露：范围内已审阅数、关键判断仍不确定数、尚未评估数、资料核实及来源覆盖限制。具体缺项保留逐岗记录，对用户补问聚合呈现。

## 验收

1. 无简历/空证据不会被自动写成低能力；反例不能通过结构校验。
2. 4年对6年等差距不硬否决，差距与放宽依据可追溯；不存在固定宽限阈值。
3. 学历已知但专业未知时，学历仍保持已知，资格综合保留未知。
4. 城市偏好独立；仅地点缺失的完整JD可完成其他维度；类型、正文、开放状态问题仍待核实。
5. 薪资缺失或差距不改变主要结果；无偏好不创设薪资目标。
6. 未知结果正常提交、合并、导出，续跑不重复领取；改变事实使旧判断失效。
7. 实际导出15列Excel，重开检查字段、文本与链接并查看渲染；旧格式回归不破坏。
8. 复用100条原用户提示词，区分旧首轮模拟证据与本轮受影响案例复测；不冒称完成100次联网求职。
9. 原报告基于完整JD重新判断，并保留原文件校验值，明确历史快照限制。
