# 全量来源复核

> 本文记录 2026-09-17 至 2026-09-18 的旧库全量审计口径。当前固定名单及后续补漏结果见 [行业公司索引](行业公司索引.md) 和 [第四轮闭环复核报告](../artifacts/wps-campus-sources-20260919/deep-api-review/第四轮闭环复核报告.md)。

本轮覆盖旧项目 **9,295 条公司记录、11,732 个登记招聘入口**；每条旧公司记录都有来源检查或与既有验证记录的对应结论，**无未归档公司记录**。登记入口数是旧库规模，不代表本轮全部独立重抓。旧库的 5 个公司库副本比对结果一致。

正式来源由 **1671 增至 1960 个公司／招聘主体**：新增 291 个、合并 2 个既有重复主体，净增 **289 个**；另修正 2 个主体范围。仍按 19 个行业分流，产品流程不变。

## 本次恢复了什么

公开接口恢复包括北森 LightBolt、前程无忧 CoAPI／XYZ、智联 Grace、牛客、Greenhouse、Oracle、顺丰集团，以及公开门户跳转中的常规 ATS 入口。每个入库配置单独验证完整职责、要求、岗位 ID 和具体 JD 链接，HTTP 200 或空列表不单独算通过。

API 能返回实习、社招或已关闭历史 JD 时，只证明来源能力；每次评估仍只纳入明确正式校招且开放的岗位。关闭历史岗位不能给当前城市建标。分页、详情正文和城市覆盖分别标记，样本验证不是全量抓取承诺。

## 覆盖边界

本次逐条检查不等于证明所有未入库公司都没有公开 API。公开入口失败、只支持页面或人工投递、空列表、正文不完整及归属不明均未作为新增可用来源。公众号图片型公告、二维码、附件和未深入的次级链接仍可能藏有新线索；本轮只对实际读到并验证的链接作结论，不声称穷尽这些图片或每条页面内链接。

已有来源沿用各自带日期证据，本轮新增和修复记录保留当次时间；接口未来可能变化。失败记录只描述本次尝试，不能解释为永久不可用。原项目只读，原始请求与复核产物保存在本 skill 的 artifacts/full-registry-review-20260917 内。
