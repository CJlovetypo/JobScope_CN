# 社招能力证据模型

新prepare使用[判断模型v5](../../../../shared/job-search-core/references/assessment-v5.md)，评估前必须读取。下文旧v4状态、例子和十二列仅用于旧运行追溯；新运行以v5为准：缺证unknown有效完成，不因年限差距否决，学历/专业/经验分开，新增城市/薪资参考/证据充分性，十五列及clarify动作。

接收学历、正式工作年限、具体工作责任与成果、相关经验、到岗安排和薪资／职级等明确偏好；无工作经验可填0。没有默认应届或毕业届别门槛，实习不自动累计为正式工作年限，带团队与预算等资深职责须有本人实践支撑。不能因标题“高级／经理”推断胜任程度。

证据三个轴独立：kind说明材料来源，claim_type区分客观实践/客观成果/主观自评/偏好，experience_type说明正式工作、实习、研究/课程/个人项目或其他场景。客观表示候选人的事实陈述，不冒充已外部核验。

每项核心任务看本人动作、责任、实际产物与反馈，团队业绩不自动归功于本人。先判断任务相关性再看质量，不按公司名、学校名、工作年数、实习次数或数字大小自动评分。工作年限作为准入条件与任务胜任程度分开。学校/个人项目在目标岗位允许的责任水平内也可提供强证据，没有实习不自动判低。

实习评估以实际实习职责为尺度，保留课程、研究和独立项目对学习与基础能力的证明，不默认要求资深人员的生产规模。社招优先核对正式工作中的责任深度、完整交付、规模与成果；JD若要求带团队、预算或长期运营，只有参与经历不能证明独立承担。跨职能/行业时解释实际可迁移任务和不可迁移部分。

按JD区分core决定性核心、supporting一般支持、bonus明确加分、eligibility资格。多选方向保留或的关系，必须条件不变成可选。对每项给direct直接实践、transferable具体可迁移或unsupported未提供支持；强度strong为本人责任和成果/实施细节充分，moderate为具体实践但部分边界缺失，weak为头衔/自评/工具罗列，none无材料。

高能力须全部核心direct且strong/moderate、至少一项strong；中能力须有核心/支持的客观中强证据和清楚迁移路径，但存在核心覆盖或深度缺口；低能力须已读足够材料且主要核心缺证，写“未提供证据”不写“确定不会”；资料不足为unknown待评估。资格和意愿不得抬高或压低能力。

引用实习/工作时，行业、团队业务、岗位职能分别记录same/adjacent/different/unknown。某维不同不必然低：高度相近的技术任务可跨业务，业务相近但职责不同也有部分价值。按具体JD决定，不能靠标签计算分数。真实不同经历能增加支持，同段经历拆多条不能重复累计。

模型应完整阅读再判断，程序只验证结构、证据引用与明显矛盾，不是事实核验或录用概率模型。
